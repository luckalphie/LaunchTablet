# LaunchTablet 0.3.0 Preview — Build 9

LaunchTablet 是为大屏设计的 macOS 原生启动台，原项目名称为 Launchpad。全屏背景配合居中紧凑网格，支持分页、搜索、文件夹及手动整理。

## 本次更新

- 统一应用、菜单、模块和安装包名称为 LaunchTablet。
- 支持简体中文和英文，默认跟随系统，可在设置中即时切换并记住选择。
- 翻译菜单、右键操作、提示、错误和辅助功能标签；默认分类随语言显示，自定义文件夹名保留。
- 兼容旧名称下的布局与快捷键偏好，新版数据优先，旧布局文件保留。
- 保留拖动排序、跨文件夹移动、浏览器网页应用归组，以及由大变小的呼出动画。

## 下载与安装

适用于 Apple 芯片（M 系列）Mac，要求 macOS 14 或以上。不提供 Intel 包。

下载 `LaunchTablet-0.3.0-9-arm64.dmg`，将应用拖入 Applications，推出镜像后启动。替换前先退出旧启动器，避免快捷键冲突。附带 `.sha256` 校验文件。

这是 Preview：采用本地临时签名，未经过 Apple Developer ID 签名和公证。首次打开可能需要在“系统设置 → 隐私与安全性”允许可信副本。

## 验证与限制

当前源码的自动化验证和实机范围见 [验证记录](../验证记录.md)。最低部署目标不代表每个 macOS 14+ 版本都完成实机验收；新版原生拖拽、触控板惯性和动画观感仍需更多机器反馈。

## English

LaunchTablet is a compact, centered app launcher for macOS, previously developed under the Launchpad project name. Build 9 introduces English and Simplified Chinese throughout the interface, instant language selection, and compatibility with the previous layout and shortcut preferences.

Download the arm64 DMG for Apple Silicon, drag the app into Applications, eject the image, and launch it. Requires macOS 14 or later. Quit the previous launcher first. Preview builds are ad hoc signed and not notarized. See the bundled installation instructions if macOS blocks a trusted copy.
