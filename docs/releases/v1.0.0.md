# LaunchTablet 1.0.0

LaunchTablet 首个正式版本：为大屏 Mac 提供全屏背景与居中应用网格，支持搜索、分页、文件夹和手动整理。

## 功能

- 五种网格范围：全屏、14 英寸、16 英寸、24 英寸、27 英寸；默认 14 英寸，设置即时生效并记住选择，小屏自动缩小。
- 全屏与 24/27 英寸模式随可用空间放大图标和名称；保留均衡边距，适配超宽屏与竖屏。
- 扩大翻页动画可见范围：全屏延伸到屏幕边缘，其它预设左右各增加一列过渡空间，受实际屏幕边界限制；静止网格保持居中。
- 简体中文与英文，默认跟随系统，可在设置中即时切换。
- 应用名称、拼音与首字母搜索，键盘导航、分层 Esc、全局呼出快捷键。
- 拖动排序、文件夹整理、隐藏与恢复应用；Edge/Chrome 网页应用分别归组，布局自动保存。
- 由大变小的呼出动画，以及收起、文件夹和隐藏应用的过渡效果；遵循系统“减少动态效果”。

## 下载与安装

适用于 **Apple 芯片（M 系列）Mac，macOS 14 或更高版本**。不提供 Intel 安装包。

下载 `LaunchTablet-1.0.0-13-arm64.dmg`，将 LaunchTablet 拖入 Applications，推出镜像后打开。升级前先在旧版本设置中退出，再替换应用。附带 `.sha256` 校验文件。

安装包使用本地临时签名，**尚未经过 Apple Developer ID 签名与公证**。如果 macOS 阻止可信副本，先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。无需关闭系统安全保护。

## 验证与已知限制

68 项本地自动化检查通过，覆盖显示范围、动画视口几何、双语、布局、迁移、搜索、键盘、模拟滚动和拖拽逻辑；DMG 完整性、arm64 架构、签名和包内双语资源已检查。

本机验证环境为 Apple 芯片、macOS 27；尚未覆盖所有 macOS 14+ 系统。新翻页的实际流畅度、原生拖拽及真实触控板惯性仍需更多实机反馈，离屏预览与模拟事件不代表全部真实操作已验收。应用分类与安装日期根据系统元数据推断，可能存在误差。

## English

The first stable release of LaunchTablet, a native macOS app launcher designed for large displays. Choose Full screen, 14-inch, 16-inch, 24-inch, or 27-inch grid areas, with saved preferences and automatic scaling on smaller screens. Larger layouts scale icons and labels, while page animations gain room to travel beyond the resting grid. English and Simplified Chinese, search, keyboard navigation, folders, drag sorting, and local layout persistence are included.

Download the arm64 DMG for an **Apple Silicon Mac running macOS 14 or later**. Drag LaunchTablet into Applications, eject the image, and launch it. Quit the previous version before upgrading. A SHA-256 checksum is included.

The package is **ad hoc signed and not notarized**. If macOS blocks a trusted copy, try opening it once, then use **System Settings → Privacy & Security → Open Anyway**. No Intel build is provided. Automated checks pass; real trackpad gestures, updated native drag interactions, animation smoothness, and all supported OS versions have not been fully validated.
