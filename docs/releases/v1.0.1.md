# LaunchTablet 1.0.1

This update fixes automatic discovery of newly installed apps and starts LaunchTablet in the background.

- Changes in application directories and their subdirectories now trigger a refresh, including Edge and Chrome web apps. A refresh requested during a scan runs again when the current scan finishes.
- LaunchTablet starts without showing its window. Click its Dock icon again or press Control + Option + Space to open it.
- The GitHub project introduction is now in English, with a link to the Chinese documentation.

## Download and install

Download `LaunchTablet-1.0.1-14-arm64.dmg` for an **Apple Silicon Mac running macOS 14 or later**. Quit the previous version, drag LaunchTablet into Applications, eject the disk image, and launch it. A SHA-256 checksum is provided alongside the DMG.

The app is **ad hoc signed and not notarized**. If macOS blocks a trusted copy, try opening it once, then use **System Settings → Privacy & Security → Open Anyway**. No Intel build is provided.

The 71 automated checks include filesystem event and concurrent refresh coverage. Background startup was checked with the isolated secondary-display build; Dock reopening and the updated drag interactions still need desktop validation. Other macOS versions have not all been tested in person.

## 简体中文

本次更新修复新安装应用无法自动加入的问题，并调整启动行为：

- 递归监听应用目录和子目录的变化，包括 Edge、Chrome 网页应用目录；扫描过程中收到新的刷新请求时会再扫描一次。
- 启动后先在后台运行，不自动弹出窗口；再次点击 Dock 图标或按 Control + Option + 空格呼出。
- GitHub 项目首页改为英文，并提供中文说明入口。

下载 `LaunchTablet-1.0.1-14-arm64.dmg`，适用于 **Apple 芯片 Mac、macOS 14 或更高版本**。升级前退出旧版本，再将应用拖入 Applications。安装包附带 SHA-256 校验文件。

安装包采用本地临时签名，**尚未经过 Apple Developer ID 签名与公证**。若 macOS 阻止可信副本，先尝试打开，再到“系统设置 → 隐私与安全性”选择“仍要打开”。不提供 Intel 安装包。

71 项自动化检查覆盖目录变化和扫描并发；后台启动已通过隔离副屏测试包检查。Dock 再次点击呼出和新版拖拽仍待实机验收，尚未覆盖全部受支持的 macOS 版本。
