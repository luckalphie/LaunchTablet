# LaunchTablet 1.0.2

This patch release fixes application discovery for launchable menu-bar applications.

- Applications with `LSUIElement = true` are now included, so apps such as Window Switcher appear in LaunchTablet even though they do not show a Dock icon. Some helper apps may also appear because this flag does not distinguish them.
- Applications explicitly marked `LSBackgroundOnly` remain excluded.
- Added regression coverage for both metadata cases; 72 local checks pass.

## Download and install

Download `LaunchTablet-1.0.2-15-arm64.dmg` for an **Apple Silicon Mac running macOS 14 or later**. Quit the previous version, drag LaunchTablet into Applications, eject the disk image, and launch it. A SHA-256 checksum is provided alongside the DMG.

The app is **ad hoc signed and not notarized**. If macOS blocks a trusted copy, try opening it once, then use **System Settings → Privacy & Security → Open Anyway**. No Intel build is provided.

## 简体中文

本次补丁修复可启动菜单栏应用无法显示的问题：

- 不再仅凭 `LSUIElement = true` 过滤应用，因此 Window Switcher 等不显示 Dock 图标的应用可以正常显示。该标记无法区分所有辅助应用，部分辅助应用也可能出现。
- 仍然排除明确声明 `LSBackgroundOnly` 的后台进程。
- 增加了两种元数据场景的回归测试，本地 72 项检查全部通过。

下载 `LaunchTablet-1.0.2-15-arm64.dmg`，适用于 **Apple 芯片 Mac、macOS 14 或更高版本**。升级前退出旧版本，再将应用拖入 Applications。安装包附带 SHA-256 校验文件。

安装包采用本地临时签名，**尚未经过 Apple Developer ID 签名与公证**。若 macOS 阻止可信副本，先尝试打开，再到“系统设置 → 隐私与安全性”选择“仍要打开”。不提供 Intel 安装包。
