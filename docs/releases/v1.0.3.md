# LaunchTablet 1.0.3

This release improves the Dock launch experience when macOS Stage Manager is enabled.

- LaunchTablet now runs as an accessory app and presents its launcher in a non-activating panel, reducing unnecessary Stage Manager app switching.
- Pin LaunchTablet to the Dock to open it by clicking its icon. Accessory apps do not automatically show a running Dock icon. The global shortcut **Control + Option + Space** remains available.
- Existing layouts, folders, hidden apps, and preferences are preserved.

## Download and install

Download `LaunchTablet-1.0.3-16-arm64.dmg` for an **Apple Silicon Mac running macOS 14 or later**. Quit the previous version, drag LaunchTablet into Applications, eject the disk image, and launch it. A SHA-256 checksum is provided alongside the DMG.

The app is **ad hoc signed and not notarized**. If macOS blocks a trusted copy, try opening it once, then use **System Settings → Privacy & Security → Open Anyway**. No Intel build is provided. Stage Manager behavior can vary across macOS versions and display setups.
