# LaunchTablet 1.0.4

- Added a menu bar icon with actions to show or hide LaunchTablet and quit the app. Menu text follows the selected interface language.
- Apps under first-level subdirectories of `~/Applications` are grouped into corresponding launcher folders. Deeper directories share that folder because nested launcher folders are not supported. Existing custom folders and hidden apps are preserved during migration; Edge and Chrome web apps retain their dedicated folders.

## Download and install

Download `LaunchTablet-1.0.4-17-arm64.dmg` for an **Apple Silicon Mac running macOS 14 or later**. Quit the previous version, drag LaunchTablet into Applications, eject the disk image, and launch it. A SHA-256 checksum is provided alongside the DMG.

The app is **ad hoc signed and not notarized**. If macOS blocks a trusted copy, try opening it once, then use **System Settings → Privacy & Security → Open Anyway**. No Intel build is provided. The new menu bar and directory migration have not yet been verified through desktop interaction.
